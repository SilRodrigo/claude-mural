Como funciona

Cada card tem um ID fixo. Cite o ID no chat ("sobre a P-03…") e a sessão acha o card direto.

P
Pergunta de uma sessão para você
A
Alinhamento: uma decisão para confirmar ou registrar
T
Pendência, com checkbox
V
Aprovação visual: um resultado para você aprovar ou pedir ajuste

Esperando você → você responde aqui → Com os agentes → a sessão aplica e escreve uma nota → Aplicado.

As sessões não recebem aviso quando você responde. Elas leem o mural quando começam a trabalhar. Para chamar uma sessão na hora, use Copiar aviso no card respondido e cole no chat da sessão indicada em "aberto por".

Arraste o quadro para mover, use a roda do mouse para o zoom e arraste um card pela faixa do ID. Cada card novo chega na área que a sessão indicou, ou em Entrada.
