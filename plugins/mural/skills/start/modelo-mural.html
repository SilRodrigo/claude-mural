Como funciona

Por que existe: as sessões do Claude têm perguntas que não precisam de resposta na hora. Em vez de interromper a conversa, elas deixam um card aqui. Você responde quando puder, de preferência com um clique, e o chat fica livre para o trabalho do momento.

Cada card tem um ID fixo. Cite o ID no chat ("sobre a P-03…") e a sessão acha o card direto.

P
Pergunta de uma sessão para você
A
Alinhamento: uma decisão para confirmar ou registrar
T
Pendência, com checkbox
V
Aprovação visual: um resultado para você aprovar ou pedir ajuste

Esperando você → você responde aqui → Com os agentes → a sessão aplica e escreve uma nota → Aplicado.

As sessões não recebem aviso quando você responde. Elas leem o mural quando começam a trabalhar. Para chamar uma sessão na hora, use Copiar aviso no card respondido e cole no chat da sessão indicada em "aberto por".

Arraste o quadro para mover, use a roda do mouse para o zoom e arraste um card pela faixa do ID. Um clique no ID copia o ID. Cada card novo chega na área que a sessão indicou, ou em Entrada.

Grampear: solte um card em cima de outro, ou de uma pilha, para grampear os dois. Você também pode marcar a bolinha no canto do card (ou usar Ctrl+clique na faixa do ID) para escolher vários e clicar em Grampear. A pilha pode ganhar um nome, ser aberta para ver todos os cards, arquivada inteira de uma vez ou desgrampeada. Com a pilha aberta, arraste um card para fora dela para tirá-lo, ou solte em cima de outro card da pilha para mudar a ordem.

Tema: o botão "Tema" alterna entre automático (segue o claude.ai), claro e escuro. A escolha fica guardada só neste navegador.
